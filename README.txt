CRICKETLIVE READ-ONLY STARTER

This starter contains no fake scores, manual score-entry form, edit buttons,
delete buttons, or sample matches. It is only a read-only layout at this stage.

FILES
- index.html: page structure
- style.css: page appearance and mobile layout
- script.js: placeholder for the live API connection

The next setup step is to choose a cricket data API, obtain an API key with
adult help if required, then use JavaScript fetch() to request its JSON and
display the returned matches here. Do not post an API key in chat or put it in
a public repository.
